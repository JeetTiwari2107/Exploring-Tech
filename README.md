# LocalGit Studio public site

This repository contains the static information and license website for LocalGit Studio. It does not contain the application source, application bundle, server, or download, and the site cannot access or edit visitor files.

## Publishing

The site is plain HTML and CSS with no build step, JavaScript, third-party scripts, forms, analytics, or runtime secrets. To publish it with GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. The public URL will be `https://jeettiwari2107.github.io/Exploring-Tech/` after GitHub Pages finishes its first deployment.
