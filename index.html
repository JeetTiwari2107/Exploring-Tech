Try it on your computer

Start with a local Git repository.

Install Node.js 22.12+ and Git 2.40+, then clone the public source and launch the local app.

git clone https://github.com/JeetTiwari2107/Exploring-Tech.git
cd Exploring-Tech
npm run setup
npm start -- --repo "C:\work\your-project"

Then open http://127.0.0.1:3000. To browse repositories under a workspace folder, use npm start -- --root "D:\workspaces".
